Uma trilha, não um trilho

O portal diz o que precisa estar pronto ao sair de cada etapa. Como chegar lá fica com o time: as skills são caminhos possíveis, nossas ou de terceiros, e nenhuma é a oficial.

O que a curadoria resolve antes de adotar

Onde a spec é gravada

A to-spec do mattpocock/skills publica a spec no tracker de issues; o setup aceita descrever outro fluxo. O superpowers grava em docs/superpowers/, mas a preferência do projeto vale mais. Cada trilha pronta diz onde a spec fica.

Idioma

As duas coleções escrevem em inglês, e o modelo da to-spec traz títulos como "Problem Statement". Se a spec sai em português só porque o AGENTS.md pede, o laboratório mede antes de qualquer skill subir para adotar.

Instruções que se contradizem

O TDD do mattpocock deixa a refatoração para a revisão; o do superpowers a tem como terceira fase e manda apagar o código escrito antes do teste. Cada trilha pronta é coerente por dentro, e a montagem livre avisa o conflito.

Origem que muda

As coleções mudam entre versões, então o portal fixa versão e commit e revalida. Mandar PR para a origem não é o caminho: o SCOPE.md do mattpocock/skills fecha propostas de skill nova.
