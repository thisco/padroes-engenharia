MCP · Model Context Protocol

Um protocolo aberto para o harness conectar o modelo a ferramentas e dados externos. Para o modelo, uma ferramenta MCP é só mais um pedido de ação; quem executa é o servidor.

onde mora
.mcp.json, .kiro/settings/mcp.json, ~/.codex/config.toml: um por harness
quando entra
a lista de ferramentas entra na sessão; o resultado de cada chamada também, e ocupa contexto
erro comum
ligar MCP para tudo, ou servidor aberto por padrão. Resultado de ferramenta é conteúdo não confiável e pode trazer injeção
práticas
P3-04 MCP fechado por padrão bloqueia · P1-11 preferir CLI + skill quando bastar orienta
referências
MCP spec 2026-07-28 · Radar Vol. 34: "MCP by default" em Caution · OWASP Agentic Top 10: ASI02 Tool Misuse

Proposta de um segundo ninho, para IA no produto: aplicação ou agente próprio → chave virtual → gateway (identidade, catálogo, orçamento, guardrails, auditoria) → modelos em três camadas. Conceitos: gateway, chave virtual, guardrail, eval, catálogo de modelos, nível de agência.
