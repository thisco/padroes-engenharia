# Mockups do brainstorming (01/10/2026)

Telas usadas para aprovar o desenho da [spec](../2026-10-01-portal-padroes-engenharia-design.md).
São fragmentos HTML feitos para uma moldura de brainstorming e, abertos sozinhos, aparecem
sem o tema da moldura. O conteúdo e o layout são a referência; o texto é rascunho e passa pela
curadoria (§11 da spec) antes de virar página.

| Arquivo | O que foi decidido |
|---|---|
| `mapa-da-visao.html` | Fontes → pilares → portal com duas portas (pessoas e agentes) |
| `benchmark-mercado.html` | O que copiar do mercado e os dois diferenciais (força declarada, `llms.txt`) |
| `espinha-sdd-v2.html` | A espinha: 12 faixas × 4 momentos, com contratos, observabilidade e LGPD |
| `monorepo-gitlab.html` | Estrutura do monorepo no molde do awesome-copilot |
| `visual-portal.html` | Página inicial (Como fazer) e página de prática no tema do kit de origem |
| `o-problema.html` | Página O problema: anatomia, cadeia, disciplinas, como combinar |
| `o-problema-falhas.html` | Os 7 padrões de falha com fonte primária |
| `conceitos.html` | Página Conceitos: o ninho com 9 peças e a página por conceito |

Depois do brainstorming, o domínio "Arquitetura de software" passou a se chamar "Arquitetura e
padrões de projeto", e a navegação ficou em três grupos (§4.2 da spec). Os mockups anteriores a
essas decisões ainda mostram os nomes antigos.
