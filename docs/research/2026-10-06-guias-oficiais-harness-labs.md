## 4. DeepSeek

**Não há guia oficial de harness, prompt de sistema ou estrutura de instruções para agentes de código.** O que existe:

- [Tool calls](https://api-docs.deepseek.com/guides/tool_calls): tool use em thinking mode "from DeepSeek-V3.2"; strict mode (beta); Chat Completions "does not support inserting tool calls mid-conversation" (usar Anthropic/Responses API).
- [Thinking mode](https://api-docs.deepseek.com/guides/thinking_mode): ligado por padrão, effort `low/high/max`; com `tools`, "the reasoning_content of all previous turns should be passed back" — senão HTTP 400. Impacto direto no harness: o loop deve preservar reasoning entre turnos.
- [Context caching on disk](https://api-docs.deepseek.com/guides/kv_cache): habilitado por padrão; hit só se "fully matches a cache prefix unit"; unidades criadas em fronteiras de request; `prompt_cache_hit_tokens`/`miss_tokens`; "best-effort". Reduz custo de prefixos repetidos (system prompt, tools, few-shot).
- [V4-Pro GA](https://api-docs.deepseek.com/news/news260813/) (2026-08-13): "low for simple tasks, high for daily Agent workflows, max for complex tasks"; Responses API nativo "optimized for Codex"; off-peak −50%.
- [Coding agents](https://api-docs.deepseek.com/guides/coding_agents) · [Codex](https://api-docs.deepseek.com/quick_start/agent_integrations/codex/) · [Anthropic API](https://api-docs.deepseek.com/guides/anthropic_api): integra Claude Code (`ANTHROPIC_BASE_URL`, `CLAUDE_CODE_EFFORT_LEVEL=max`), Codex (`wire_api = "responses"`, contexto 1.048.576, effort `high` default), OpenCode/OpenClaw. Nenhuma orientação sobre prompts, instruções ou guardrails.

## 6. Divergências ou lacunas

- **Limites de instrução**: Anthropic recomenda (<200 linhas, soft); Codex corta em 32 KiB (hard); Antigravity 24 KB/arquivo + 20K tokens agregados com rebaixamento automático; Gemini CLI não documenta limite.
- **Ativação de regras**: Antigravity tem 4 triggers nativos (`always_on/model_decision/glob/manual`); Claude Code usa `paths` em `.claude/rules/` + descrição de skill; Codex só escopo por diretório (nested AGENTS.md), sem glob.
- **Mecanismo de enforcement sem formato comum**: Claude Code hooks (shell/prompt/agent) + permissions; Codex sandbox + `approval_policy` + rules Starlark + hooks; Gemini policy engine TOML com tiers + hooks; ADK callbacks em código. Um framework precisa de adaptadores por harness; só a semântica "evento → allow/deny/ask" é compartilhada.
- **Tool search e programmatic tool calling** são features da API Anthropic sem equivalente documentado nos outros harnesses.
- **Cache**: Anthropic exige breakpoints (ou `cache_control` top-level) e cobra escrita (1,25×); Google e DeepSeek são automáticos e best-effort; mínimos e TTLs diferem.
- **Visão de harness**: OpenAI inclui o repositório inteiro (linters, CI, `docs/`, observabilidade); Anthropic foca em arquivos de estado + hooks + skills; Google em políticas/hooks do CLI.
- **DeepSeek**: nenhuma orientação de harness; a exigência de reenviar `reasoning_content` com tools é uma restrição que harnesses genéricos precisam acomodar.
- **Antigravity workflows** serão descontinuados (nov/2026) — formatos de "comando" tendem a convergir em SKILL.md.

## 7. Recomendações para economia de tokens no roteamento de práticas

1. **Sempre carregado (núcleo ≤ ~100–200 linhas)**: comandos de build/teste, convenções que diferem do padrão, regras "nunca X", e um **índice** apontando para skills/rules — nunca descrições arquivo-a-arquivo nem docs de API ([Claude](https://code.claude.com/docs/en/best-practices), [OpenAI](https://openai.com/index/harness-engineering/)). Teste por linha: "removê-la causaria erro?"
2. **Sob demanda**: cada prática/domínio como skill (SKILL.md < 500 linhas, referências a um nível) com `description` curta e com gatilhos (≤1.024 chars Anthropic; orçamento total 8.000 chars no Codex; 1.536 chars na listagem do Claude Code). Práticas por área de código em rules com `paths` (Claude), `glob` (Antigravity) ou AGENTS.md aninhado (Codex).
3. **Regras duras → hooks/policies/lints**, não prosa: custo de contexto zero até disparar; mensagens de erro com remediação viram contexto só quando necessário ([features-overview](https://code.claude.com/docs/en/features-overview), [harness post](https://openai.com/index/harness-engineering/)).
4. **Skills com efeitos colaterais**: `disable-model-invocation: true` (Claude) / `allow_implicit_invocation: false` (Codex) — zero tokens até invocação manual.
5. **Prefixo cacheável**: manter ordem `tools → system → instruções estáveis → conteúdo dinâmico`; não injetar timestamps, git status ou saída de hooks no prefixo estável; manter o conjunto de tools fixo na sessão (mudar tools invalida todo o cache na Anthropic); mesma lógica em Gemini e DeepSeek. Em sessões longas, preferir compaction server-side e `clear_at_least` alto para não fragmentar o cache.
